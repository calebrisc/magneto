## Queued 2026-08-26 (telemetry session — apply to spec.html as v0.5)

- **Telemetry architecture decided (approved by Cale 8/26): dongle-side archive.** Full design + rationale in new `docs/TELEMETRY.md`. Summary: the nRF54L15 has no USB, so the mouse's USB-C is charge-only; the dongle (which already receives every report) gets SPI NAND (1–4 Gbit, ~$1–3) and archives the stream continuously; mouse keeps only a small dropout buffer with backfill. Wooting-style web app reads the archive over WebUSB/WebHID and labels matches client-side — no installed software required, data stays on user hardware. spec.html: new Telemetry section + Parts tab (dongle NAND) + Radio tab (backfill airtime note for 8K streaming mode).
- **Game labeling: CS2 GSI stays optional live enrichment; Valorant gets retroactive labeling via match-history APIs** (per-kill timestamps → fight segmentation), optional live presence via Riot Client local API (unofficial, read-only, never load-bearing). Both are adapters emitting the same match-state event schema. Clock alignment = anchors on host contact (cs2-bench `.anchor` pattern) + session markers + kill-feed correlation; layer-3-only recovery is a bench-verify item.
- **Charge passthrough port on dongle/puck (approved by Cale 8/26):** USB-C 5 V VBUS passthrough (no data/hub/PD), Rp advertises 1.5 A, polyfuse so a greedy device can never brown out the radio. Preserves the one-cable charge habit without unplugging the dongle; mouse plays wirelessly while charging; recording never stops. spec.html: Radio/Parts tabs + dongle/puck drawing.
- **No wired data mode — consciously accepted.** With the dongle lost, the mouse is inert (54L15 has no USB). Mitigations: charge passthrough + spare dongle per unit. Revisit trigger: LAN/tournament wired-mouse rules; any revisit is a silicon change that must precede mouse PCB layout. State this in §Radio.

## Queued 2026-08-18 (design audit session — apply to spec.html as v0.5)

- **Lab-access assumption corrected:** spec assumed "university lab access (scope, spectrum analyzer, VNA)." Engineer (entering 3rd year this week) likely has NO standing lab access — he should confirm what his coursework grants this semester. Impact: none on M1/M2 (kHz signals; the DK's ADC serves as data logger, a ~$40 hobby scope covers debugging, free myTI sample in-amps front-end the ADC). The real instrument needs — spectrum analyzer (piezo EMI, P3) and VNA (antenna tuning) — are months out; options then: coursework/capstone lab access, Fab Lab Tulsa / makerspace network, or Cale's business contacts.

- **Two-track structure made explicit:** the six-unit mouse build is the optical (PAW3950) track per v0.4. Magnetic-pad tracking ("Magneto") is a parallel research track with its own go/no-go plan — now on paper in `docs/MAGNETIC_TRACKING.md` (previously existed only in claude.ai planning chats). If its M2 gate passes, it targets mouse v2. spec.html should state this in §02 so "tracking" is unambiguous.
- **Scroll detent revision (approved by Cale 8/18): permanent-magnet-biased detents.** v0.4 design held detents with continuously-driven coils — a constant battery drain in the default mode. Revised: a small permanent magnet provides passive detent flux through the toothed rim (zero idle power, identical feel — same flux-through-teeth physics), coils now only (a) cancel PM flux for freespin (brief, only while spinning), (b) brake for coast curves, (c) trim detent strength per profile. Feel is unchanged; the always-on battery cost moves to the rarely-used mode. Update §04 + anatomy §03.
- **Fork B sourcing note: include a bender/amplified piezo candidate.** A flat piezo patch bonded to the plate produces only microns of displacement — commercial piezo haptics use mechanically amplified configurations (benders/domes). Sourcing only flat discs would rig the bench-off toward the LRA. Add to §10 open items: at least one bender-style piezo in the P1 order.
- **Underside puck bay (approved by Cale 8/18): add to v1 chassis (§05/§08 + P4 CAD).** Superlight-style circular bay in the underside rear shell with twist-lock ring and 2–4 reserved spring-contact pads to the mainboard (<1 g, <$1). v1 uses: dongle garage / weight pucks / blank cover. Future pucks the contacts enable: pad-repair write head (see MAGNETIC_TRACKING.md repair §), inductive charging. Rear location is mass-neutral by default (bay is a hole; heavy pucks are temporary by design).
- **M2 addendum: bench-test the NdFeB repair tile** (~$10) — self-aligning contact-rewrite of damaged pad regions; see MAGNETIC_TRACKING.md.
- **ADC throughput flag (magnetic track):** 3 TMR sites × sin/cos = 6 channels pushes nRF54L15 SAADC near its ceiling at flick-speed sample rates; validation phases dodge this (speed proven on 2ch, geometry on 6ch slow), production answer may be an external ADC. Lives in MAGNETIC_TRACKING.md; spec.html mention only if M2 passes.
